# Продакшен-чеклист

Перед тем как дать ссылку папе и начать реальную работу:

## 1. Cloudflare

- Создать Cloudflare Pages проект.
- Подключить репозиторий GitHub.
- Создать D1 базу `uman-transfer-crm`.
- Привязать D1 к Pages:
  - Binding name: `DB`
  - Database: `uman-transfer-crm`
- Вставить реальный `database_id` в `wrangler.toml`.
- Применить миграции:

```bash
npx wrangler d1 migrations apply DB --remote
```

## 2. Первый вход

- Войти как `admin / admin123`.
- Сразу сменить пароль админа.
- Создать реальные кабинеты водителей.
- Отключить или удалить тестовых водителей, если они не нужны.

## 3. Проверка с телефона

- Открыть сайт с телефона.
- Войти как админ.
- Создать тестовый заказ.
- Назначить водителя.
- Войти как водитель с другого телефона или в другом браузере.
- Проверить, что водитель видит только свой заказ.
- Изменить статус поездки.
- Проверить, что админ видит изменение.

## 4. Защита данных

- Открыть `/admin/safety`.
- Скачать CSV "Все заказы".
- Проверить восстановление удалённого тестового заказа.
- Сделать первый полный SQL-бэкап:

```bash
zsh backup-cloudflare.command
```

## 5. Регулярный порядок

- Раз в неделю запускать `zsh backup-cloudflare.command`.
- Хранить `.sql` файл не только на компьютере, но и в облачном диске.
- Перед обновлениями проекта всегда делать бэкап.

# Защита данных

Эта CRM рассчитана на рабочее использование через Cloudflare Pages и Cloudflare D1.

## Как должны храниться рабочие данные

Для реальной работы данные должны храниться в Cloudflare D1, а не только на локальном компьютере.

Правильная схема:

```text
Телефон папы -> Cloudflare Pages -> Cloudflare D1
```

В этом режиме:

- телефон не хранит базу;
- твой Mac может быть выключен;
- перезапуск локального сервера не влияет на рабочие данные;
- данные остаются в D1 после перезапуска сайта;
- заказы не удаляются сразу, а переносятся в удалённые и могут быть восстановлены админом.

## Что уже сделано в проекте

- Рабочая база: Cloudflare D1.
- Сессии: HttpOnly cookie.
- Роли: admin и driver.
- Журнал действий: кто и что изменил.
- Мягкое удаление заказов: удалённый заказ можно восстановить.
- Страница админа `/admin/safety`: CSV-экспорт и восстановление удалённых заказов.
- Локальная база для тестов хранится отдельно в `local-database`.

## Что делать, чтобы данные не потерять

### 1. Перед реальной работой

Создайте D1 базу в Cloudflare, привяжите её к Pages как `DB` и примените миграции:

```bash
npx wrangler d1 migrations apply DB --remote
```

### 2. Каждую неделю делайте полный SQL-бэкап

Бэкап работает только после того, как удалённая база D1 уже создана в Cloudflare и `database_id` вставлен в `wrangler.toml`.

```bash
cd /Users/23force/Documents/Codex/2026-06-04/new-chat/work/uman-transfer-crm
zsh backup-cloudflare.command
```

Файл появится в папке:

```text
backups/
```

Скопируйте этот файл в Google Drive, iCloud Drive или на флешку.

### 3. Перед важными изменениями делайте бэкап

Например перед:

- обновлением CRM;
- изменением структуры базы;
- массовым удалением или исправлением заказов;
- сменой настроек Cloudflare.

### 4. Используйте страницу "Защита данных"

В админке откройте:

```text
/admin/safety
```

Там можно:

- скачать CSV с заказами;
- скачать CSV с водителями;
- скачать CSV с машинами;
- скачать CSV с журналом действий;
- восстановить случайно удалённый заказ.

## Восстановление

Если случайно удалили заказ:

1. Откройте `/admin/safety`.
2. Найдите заказ в блоке "Удалённые заказы".
3. Нажмите "Восстановить".

Если пропали данные из-за серьёзной ошибки:

1. Сначала не делайте новых изменений в CRM.
2. Проверьте Cloudflare D1 Time Travel.
3. Если нужен файл-бэкап, используйте последний `.sql` из папки `backups/`.

Cloudflare D1 Time Travel позволяет откатить базу к предыдущему состоянию. На бесплатном плане доступен откат на ограниченный период, поэтому ручные `.sql` бэкапы всё равно нужны.

## Важное ограничение

Ни одна система не даёт абсолютной гарантии "данные невозможно потерять". Надёжная схема состоит из нескольких уровней:

- основная база в Cloudflare D1;
- журнал действий;
- мягкое удаление;
- регулярный SQL-бэкап;
- отдельное хранение копии бэкапа.
